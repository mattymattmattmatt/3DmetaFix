        Under the hood
        
      Serious engineering, zero fuss.
      
        
      Everything happens locally with plain web tech: no servers, no uploads, no installs.
      
      
      
      
      
        
      
          
      1
      
          
      Reads only the header
      
          
      MP4 and MOV files keep their index in a small moov box. 3DmetaFix walks the box tree and loads just that index, so a 100 GB file opens in milliseconds.
      
        
      
        
      
          
      2
      
          
      Looks at the picture
      
          
      Smart detect samples frames and scores every layout. It correlates the two halves for stereo, checks whether the edges wrap into a full 360°, and looks for the stretching that marks a spherical projection.
      
        
      
        
      
          
      3
      
          
      Rewrites, then proves it
      
          
      It writes Google Spherical V1 and V2 metadata, reusing spare padding so no media byte moves. When bytes do have to move, every chunk offset is remapped, with 64-bit promotion past 4 GB. The saved file is then re-read and checked byte by byte.
      
        
      
      
      
    
      

    
      
      
      Questions
      
      
      
        
      Will this reduce my video's quality?
      No. Nothing is re-encoded. The audio and video streams are copied bit-for-bit, and only a few hundred bytes of metadata change. After saving, 3DmetaFix re-reads the new file and compares media bytes against the original.
      
        
      Is my video uploaded anywhere?
      Never. The page is static. All reading, analysis and writing happen inside your browser, so you can even disconnect from the internet once it's loaded.
      
        
      What's the difference between V1 and V2 metadata?
      V1 is Google's original XML tag stored in the video track. V2 adds compact binary boxes (st3d for stereo, sv3d for projection) inside the video sample description. Writing both gives the widest compatibility with YouTube, VLC, FFmpeg-based players and most headset players. V2 is what describes a 180° field of view.
      
        
      Which layout is my video?
      Smart detect usually knows. As a rule of thumb: a 2:1 frame is either 360° 2D (one panorama) or VR180 3D side-by-side (two square eyes). A 1:1 frame is usually 360° 3D top-bottom. Use the Headset view preview to check: if the layout is right, you'll see a single clean scene as you look around.
      
        
      My footage shows two circles (fisheye). Can this fix it?
      Metadata can't change pixels. Dual-fisheye footage must first be converted to equirectangular with your camera's software (for example Canon EOS VR Utility or Insta360 Studio). Then add metadata here.
      
        
      Which browsers work best?
      Chrome and Edge save straight to disk with live progress and on-disk verification. Firefox and Safari download the result instead. The preview depends on your browser's codec support (HEVC needs hardware support); all metadata features work regardless.
